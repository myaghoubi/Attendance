How to get the APK (about 30-60 minutes, free):
1. Create a GitHub repository and upload everything in this folder (keep the .github folder).
2. Open the "Actions" tab -> "Build APK" -> "Run workflow".
3. When it finishes, download the "attendance-apk" artifact (a zip containing the .apk).
4. Install it on the phone (allow "install unknown apps").
First launch: grant the photo/storage permissions, then close and reopen the app once.
If the build fails at OpenCV, send the log.
